2. Open index.html in a browser (Chrome, Edge, Firefox).
3. Select a chapter. All 50 chapters and the Prologue contain detailed study notes.

5. Use Aa to change font size, and the light/dark control for theme.
6. Mark chapters as completed to track progress. Progress is stored in this browser, locally.
7. Previous/Next buttons or arrow keys move between chapters.
